# 📖 Quranic AI Assistant (v2)

An AI-powered assistant that answers questions about the Quran using RAG
(Retrieval-Augmented Generation), with a Streamlit interface.

**By Classic Mentor.**

## Features
- Structured answers (verses, Juz, Rukus, Sajda) from a JSON knowledge base
- Semantic search over the full Quran text
- AI answers grounded in the source, with retrieved passages shown
- Adjustable retrieval and an educational-use disclaimer

## Note
This is an educational tool. Answers are AI-generated and may be imprecise.
For religious rulings, please consult qualified scholars.
